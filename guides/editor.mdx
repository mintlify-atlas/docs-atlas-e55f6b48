LInjector uses the Monaco editor as its built-in code editor, giving you a professional scripting environment directly inside the application. Monaco is the same editor engine that powers Visual Studio Code, so if you have ever written code in VS Code, the experience will feel immediately familiar. This means you get full syntax highlighting for Luau, IntelliSense-style autocomplete, multi-cursor editing, and all the other quality-of-life features that make writing scripts fast and comfortable.

## What is the Monaco editor?

Monaco is Microsoft's open-source code editor component, used at the core of Visual Studio Code. By embedding Monaco, LInjector avoids building a custom text editor from scratch and instead gives you a battle-tested, feature-rich editing surface that millions of developers rely on daily. The result is an executor interface that feels less like a niche tool and more like a real development environment.

The Luau syntax highlighting grammar used in LInjector was originally developed by [Krnl](https://krnl.place/) and subsequently edited by [Depso](https://github.com/depthso) to refine how Luau-specific constructs are tokenized and colored.

## Writing a Luau script

Below is a simple example that demonstrates how a well-formatted Luau script looks in the editor. The highlighting will color keywords like `local` and `for`, distinguish string literals from variable names, and dim comments to keep them visually separate from code.

```lua
-- Move the local player's character to a new position
local Players = game:GetService("Players")
local player = Players.LocalPlayer
local character = player.Character or player.CharacterAdded:Wait()
local humanoidRootPart = character:WaitForChild("HumanoidRootPart")

-- Teleport the character 50 studs forward
local currentPosition = humanoidRootPart.CFrame
humanoidRootPart.CFrame = currentPosition + Vector3.new(0, 0, -50)

print("Teleport complete for: " .. player.Name)
```

The Monaco editor in LInjector behaves just like VS Code. If you are comfortable in VS Code, you already know how to navigate, select, and edit scripts here. Keyboard muscle memory transfers directly.

## Autocomplete in practice

When you type `game:GetService("`, the editor will suggest known Roblox service names. When you access a variable like `humanoidRootPart.`, it attempts to suggest properties and methods based on known Luau types. While the autocomplete is not a full Roblox LSP server, it significantly reduces typos and speeds up writing repetitive boilerplate.

## Themes and appearance

Monaco supports multiple color themes. LInjector applies a default dark theme suited to long scripting sessions. If the project's source has been customized with a different theme configuration, it will be reflected automatically when you build and run LInjector from source.
