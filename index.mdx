LInjector is a minimal, open-source Luau Script IDE designed for developers who want full transparency and control over their Roblox scripting environment. Built with C# and .NET Framework 4.8, it features the Monaco editor (the same engine that powers Visual Studio Code), a memory-optimized tab system, and a clean architecture that makes it easy to fork and customize with your own DLL.

## Get started

<Steps>
  <Step title="Download or clone LInjector">
    Get the source from [GitHub](https://github.com/WeritoP/LInjector-FORKED-) or download a pre-built release.
  </Step>
  <Step title="Open in Visual Studio 2022">
    Open `LInjector.sln`, set the build target to **Release x86**, and build the solution with `Ctrl+Shift+B`.
  </Step>
  <Step title="Provide a compatible DLL">
    LInjector requires a working injection DLL for your target game. See [DLL Integration](/development/dll-integration) for details.
  </Step>
  <Step title="Write and execute Luau scripts">
    Launch LInjector, open the Monaco editor, write your script, and click **Execute**.
  </Step>
</Steps>

<Note>
  The UWP version of Roblox is currently patched due to Hyperion/Byfron. LInjector continues to work — see [FAQ](/reference/faq) for the current status and alternatives.
</Note>
