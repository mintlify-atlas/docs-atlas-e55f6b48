LInjector is a Windows desktop application, so getting started requires a Windows machine and a compatible injection DLL for Roblox. This guide walks you through both the pre-built release path and the source-build path, then shows you how to write and execute your first Luau script.

## Prerequisites

Before you begin, make sure you have:

- **Windows** (LInjector is a Windows Forms application and does not run on macOS or Linux)
- **A compatible injection DLL** for Roblox (LInjector provides the IDE shell; you supply the DLL that performs the actual injection)
- **Visual Studio 2022** with the .NET desktop development workload — only required if you are building from source

## Two ways to get LInjector

You can either use a pre-built release binary or compile LInjector yourself from the GitHub source. Building from source is recommended if you want to modify the injection logic or customize the UI.

- **Pre-built release** — Download the latest release from [GitHub](https://github.com/WeritoP/LInjector-FORKED-) and run the executable directly. No compilation required.
- **Build from source** — Clone the repository, open it in Visual Studio 2022, and compile a Release x86 build. See [Build from source](/building-from-source) for step-by-step instructions.

## Execute your first script

<Steps>
  <Step title="Launch LInjector">
    Run the LInjector executable. The application window opens with the Monaco editor in the center and a tab bar across the top.
  </Step>
  <Step title="Open a script tab">
    A default tab is already open when LInjector starts. Click the **+** button in the tab bar to open additional tabs if you want to work with multiple scripts at once.

    <Tip>
      The tab system is optimized to use less than 1 GB of RAM with 40 or more tabs open. You can keep an entire library of scripts open simultaneously without worrying about memory pressure.
    </Tip>
  </Step>
  <Step title="Write or paste your Luau code">
    Click inside the editor and write your script. The Monaco editor provides Luau syntax highlighting, so keywords, strings, and comments are color-coded as you type.

    Here is a minimal script to confirm everything is working:

    ```lua
    print("Hello from LInjector!")
    ```

    You can also try a simple game modification to verify injection is working correctly:

    ```lua
    -- Walk speed modifier example
    local player = game.Players.LocalPlayer
    local character = player.Character or player.CharacterAdded:Wait()
    local humanoid = character:WaitForChild("Humanoid")

    humanoid.WalkSpeed = 50
    print("Walk speed set to 50")
    ```
  </Step>
  <Step title="Connect Roblox and inject">
    Make sure Roblox is running and you are in a game session. LInjector needs an active Roblox process to attach to before you execute a script.
  </Step>
  <Step title="Click Execute">
    Click the **Execute** button. LInjector attaches to the Roblox process using your configured DLL — typically in around 300 milliseconds — and runs the script in the game context.
  </Step>
</Steps>
